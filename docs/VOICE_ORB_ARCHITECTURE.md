# Voice Orb & Audio Architecture

## Overview
The **Voice Orb** is the central interactive interface of the workplace assistant. It renders an animated glowing 3D orb that transitions across states (`idle`, `listening`, `thinking`, `speaking`) in response to employee voice interactions and incoming audio.

## Technical Components
1. **Visual State Machine**:
   - `idle`: Gentle breathing pulsation with role-themed gradients.
   - `listening`: Dynamic soundwave ripple effect matching microphone audio amplitude.
   - `thinking`: Dual-arc spinning aurora indicating tool calling or RAG query in progress.
   - `speaking`: Oscillating wave animation synchronized with Murf AI Falcon TTS playback.

2. **Agora RTC Audio Connection (`src/lib/agoraClient.ts`)**:
   - Initializes `agora-rtc-sdk-ng` client (`mode: "rtc"`, `codec: "vp8"`).
   - Joins isolated audio channel (`emp-session-{userId}`) using token generated by the server.
   - Publishes local microphone audio track.
   - Subscribes to remote audio track from the Agora Conversational AI cloud agent.

3. **Murf AI Falcon Speech Synthesis**:
   - Server returns Murf Falcon synthesized audio URL or base64 stream (`en-US-falcon-marcus`).
   - Client plays the audio stream directly; falls back gracefully to Web Speech API if in offline simulation mode.

4. **Judge 1-Click Test Prompts**:
   - Rendered directly underneath the orb for each role.
   - Judges can click any prompt (e.g. *"Hire Priya as an HR Manager"*, *"Find the top 3 candidates for Backend Engineer"*, *"Create a GitHub issue titled 'Fix payment webhook timeout', assign it to Rohan, and email him"*) to execute hands-free voice commands instantly.
